PROJECT NAME

AlgoTrade Simulator

PROJECT OVERVIEW

Build a full-stack web application that allows users to create, test, and compare algorithmic trading strategies using historical stock market data.

The platform should provide a coding environment where users can write trading strategies using a simplified C++-style syntax. Users can select one or more stocks, define a historical testing period, execute their strategy against historical market data, and view detailed performance metrics and visualizations.

The platform should also include an AI-powered assistant capable of converting natural language, pseudocode, or algorithm descriptions into executable strategy code.

The application should be portfolio-quality, visually polished, highly interactive, and designed similarly to modern trading and quantitative analysis platforms.

FINAL GOAL
